# 手机端使用指南

## 首次设置

1. 安装 QDBlocker、官方 PCAPdroid 及官方 PCAPdroid mitm。新安装的 QDBlocker 名单为空。
2. 在 PCAPdroid 设置中开启 TLS 解密，按照向导安装它在手机上生成的 CA 证书。
3. 打开 QDBlocker →“插件设置与导出脚本”，将 `QDBlocker.py` 导出到 `Documents/QDBlocker` 文件夹。
4. 打开 PCAPdroid mitm → Addons → Set user dir，选择这个文件夹并允许目录读取。刷新后开启 QDBlocker 脚本。无需“所有文件访问”权限。
5. Wi-Fi 代理设为“无”。从 QDBlocker 点击“开启 / 检查 / 停止屏蔽”，确认系统 VPN 和控制授权。
6. 进入起点刷新“评论和 @”，或关闭后重新打开阅读段评面板。

首次步骤完成后，日常无需重新安装证书或选择脚本。手机重启后，从 QDBlocker 重新启动屏蔽。

## 黑名单

每行填写一条规则，例如：

```text
uid:123456789
name:测试用户
```

点击“保存名单”，等待约 2 秒，再刷新起点或重新打开段评。纯数字会自动保存为 UID 规则。删除对应行并保存即可取消。昵称完全匹配，可能误伤同名用户，也会受改名影响；建议优先使用 UID。示例数据不对应任何指定真实用户。

## 阅读段评

打开“启用黑名单过滤”和“屏蔽阅读中的黑名单段评”。当黑名单用户回复你的主评论时，仅隐藏其回复及随条图片，保留你的主评论。主评论作者命中时，隐藏该主评论及关联回复。

通过每条记录的作者字段匹配，不使用正文、被回复者 ID 或引用中的名字判断作者。未知结构保持原样，避免按任意文字误删。

## 停止与状态

- 关闭首页总过滤开关：暂时不过滤，VPN 仍运行。
- 关闭段评开关：段评不过滤，消息过滤仍有效。
- 控制页点击“停止手机屏蔽”：停止 VPN 并释放通道。
- 首页显示插件通信时间和累计过滤条数。重复刷新会重复计数，不代表唯一消息数量。启动成功只表示服务启动，请结合计数和页面显示判断。

## 后台与网络

不必一直显示 QDBlocker 界面。需要保留 PCAPdroid 和 mitm 插件；可在手机提供相应设置时允许后台运行、自启动，将电池策略设为不限制。无法保证永远不被系统结束。

仅起点加入 VPN。起点其他网络功能也可能经过转发，有额外耗电和延迟。其他应用不加入此 VPN；开启另一 VPN 前，先停止手机屏蔽。Wi-Fi 代理保持“无”。

## 更新与故障排查

- 修改名单：保存后等待约 2 秒，刷新页面。
- 更新脚本：重新导出并启用，再停止和开启屏蔽。证书未变时不用重复安装。
- 页面无法联网：先停止屏蔽确认原版联网；确认插件、证书和脚本已启用，并从 QDBlocker 启动正确配置。
- 新版本起点失效：提交版本、入口和虚构数据结构，不要上传 Cookie、Token、证书私钥或私人评论。
- 所有行都被过滤时，客户端可能停止翻页，当前保留这一限制。
